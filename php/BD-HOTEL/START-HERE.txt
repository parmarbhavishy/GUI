┌─────────────────────────────────────────────────────────────────┐
│  🛠   MANUAL WAY  ·  four steps                                  │
└─────────────────────────────────────────────────────────────────┘

STEP 1  ·  Copy this entire "BD-HOTEL" folder into XAMPP's htdocs.

   Windows : C:\xampp\htdocs\BD-HOTEL\
   macOS   : /Applications/XAMPP/htdocs/BD-HOTEL/
   Linux   : /opt/lampp/htdocs/BD-HOTEL/

   The final file  htdocs/BD-HOTEL/index.php  MUST exist.
   DO NOT put it in  htdocs/BD-HOTEL/BD-HOTEL/  !

STEP 2  ·  Start Apache + MySQL in XAMPP Control Panel.
           Both should show green "Running" indicators.

STEP 3  ·  Import the database.
           a) Open  http://localhost/phpmyadmin
           b) Click "Import" at the top
           c) Choose file: BD-HOTEL/database/bdhotel.sql
           d) Click "Go" at the bottom
           You'll see "Import has been successfully finished."

STEP 4  ·  Open the site.
           http://localhost/BD-HOTEL/

┌─────────────────────────────────────────────────────────────────┐
│  🐛  COMMON PROBLEMS                                             │
└─────────────────────────────────────────────────────────────────┘

  "Not Found — The requested URL /BD-HOTEL/ was not found"
     → The BD-HOTEL folder is NOT inside htdocs.
     → In File Explorer, verify this file exists:
         C:\xampp\htdocs\BD-HOTEL\index.php
       If it's at  C:\xampp\htdocs\BD-HOTEL\BD-HOTEL\index.php
       (nested)  →  move the inner folder up one level.
       If it's named  BD-HOTEL-main  (from GitHub download)
                    → rename to  BD-HOTEL

  Apache won't start on Windows (port 80 conflict with Skype/IIS)
     → XAMPP → Config → httpd.conf
       Change  "Listen 80"  to  "Listen 8080"
       Then use  http://localhost:8080/BD-HOTEL/

  "Database connection failed"
     → MySQL not started, or you set a MySQL root password.
     → Edit  database/db_connect.php  and put your password in DB_PASS.

  Page loads but no CSS / no images
     → You have the folder in the wrong place.
     → Visit  http://localhost/BD-HOTEL/check.php  first;
       it will tell you exactly what's wrong.

  Everything looks blue / broken
     → Same as above. Visit check.php.
